¿Por qué existe este juego?

Impostor de Catequesis nació de una idea simple: tomar la mecánica divertida del juego "Impostor" que todos conocen, y darle un propósito más profundo.

🎮 La idea

Quería crear una herramienta para que grupos de catequesis, jóvenes parroquiales y comunidades puedan aprender jugando. No se trata solo de adivinar: se trata de conversar, escuchar y compartir la fe de forma natural y entretenida.

🤖 ¿Cómo se hizo?

Este proyecto fue desarrollado con ayuda de inteligencia artificial, desde el código hasta las palabras del juego. Fue un experimento para demostrar que la tecnología puede servir a la misión evangelizadora cuando se usa con intención.

✨ El corazón

Cada palabra, pista y categoría fue pensada para inspirar, enseñar y conectar. Si este juego ayuda a que alguien se acerque más a Jesús, a la comunidad o a la oración, entonces cumplió su propósito.
